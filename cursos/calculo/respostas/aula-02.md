# Respostas — Aula 02

1. Substituição direta (denominador 3 ≠ 0): (1²·2 + 3·2)/(1 + 2) = 8/3.
2. Pelo eixo x (y = 0): x²/x² = 1. Pelo eixo y (x = 0): −y²/y² = −1. Valores diferentes ⟹ **não existe**.
3. Em polares: x²y/(x² + y²) = r cos²θ sen θ → 0 (independe de θ). **Limite = 0.** (Ou: |x²y/(x²+y²)| ≤ |y| → 0.)
4. Por y = mx: m²x³/(x² + m⁴x⁴) = m²x/(1 + m⁴x²) → 0 (todas as retas dão 0). Pela parábola x = y²: y²·y²/(y⁴ + y⁴) = 1/2. Valores diferentes ⟹ **não existe**.
5. Com u = x² + y² → 0, sen u/u → 1. **Limite = 1.**
6. (x² − y²)/(x − y) = x + y (para x ≠ y) → 1 + 1 = **2**.
7. Pelo exercício 3, o limite em (0, 0) é 0 = f(0, 0). **Sim, é contínua** na origem.
8. O limite é 1 (exercício 5). Para ser contínua, **c = 1**.
9. ln é contínua para argumento > 0 ⟹ f contínua onde x² + y² − 4 > 0, isto é, **fora do círculo de raio 2** (x² + y² > 2²).
