# Respostas — Aula 11

1. (∫₀¹ x dx)(∫₀² y dy)(∫₀³ z dz) = (1/2)(2)(9/2) = **9/2**.
2. ∫₀¹ ∫₀^(1−x) ∫₀^(1−x−y) dz dy dx = **1/6**.
3. ∫₀¹ ∫₀^(1−x) (1 − x − y)²/2 dy dx = **1/24**.
4. Sombra no plano xy: triângulo x ≥ 0, y ≥ 0, 2x + 3y ≤ 6. V = ∫₀³ ∫₀^((6−2x)/3) (6 − 2x − 3y) dy dx = **6**. (Pirâmide: base 3 × 2 /2 = 3 e altura 6 ⟹ (1/3)(3)(6) = 6 ✓.)
5. Por simetria, cada termo vale 1/2: **3/2**.
6. ∫₀¹ ∫₀ˣ ∫₀^(x+y) y dz dy dx = ∫₀¹ ∫₀ˣ y(x + y) dy dx = ∫₀¹ (x³/2 + x³/3) dx = (5/6)(1/4) = **5/24**.
7. G: 0 ≤ x ≤ y, 0 ≤ y ≤ 1, 0 ≤ z ≤ √(1 − y²). ∫₀¹ ∫₀^y ∫₀^√(1−y²) z dz dx dy = ∫₀¹ y(1 − y²)/2 dy = **1/8**.
8. ∫₀² ∫₀^(4−x²) ∫₀^(4−x²−y) dz dy dx = ∫₀² (4 − x²)²/2 dx = **128/15**.
