# Respostas — Aula 05

1. dz/dt = 2xy·(2t) + x²·(3t²) = 2t⁵·2t + t⁴·3t² = 4t⁶ + 3t⁶ = **7t⁶**. (Substituindo antes: z = t⁴·t³ = t⁷ ⟹ 7t⁶ ✓.)
2. w_x = y e^(xy), w_y = x e^(xy); xy = u² − v². ∂w/∂u = y e^(xy)·1 + x e^(xy)·1 = (x + y)e^(xy) = **2u e^(u² − v²)**. ∂w/∂v = y e^(xy)·1 + x e^(xy)·(−1) = (y − x)e^(xy) = **−2v e^(u² − v²)**.
3. F = x³ + y³ − 6xy. Fₓ = 3x² − 6y, F_y = 3y² − 6x. dy/dx = −Fₓ/F_y = **(2y − x²)/(y² − 2x)**. Em (3, 3): (6 − 9)/(9 − 6) = **−1**.
4. z_x = 2x, z_y = 2y; x_u = v, y_u = 1/v; x_v = u, y_v = −u/v². ∂z/∂u = 2uv·v + 2(u/v)(1/v) = **2u(v⁴ + 1)/v²**. ∂z/∂v = 2uv·u + 2(u/v)(−u/v²) = **2u²(v⁴ − 1)/v³**.
5. F = x² + y² + z² − 14. ∂z/∂x = −Fₓ/F_z = −2x/(2z) = −x/z = **−1/3**.
6. w_x = y, w_y = x + z, w_z = y. dw/dt = y·1 + (x + z)·2t + y·3t² = t² + (t + t³)2t + t²·3t² = **3t² + 5t⁴**. (Conferência: w = t³ + t⁵.)
