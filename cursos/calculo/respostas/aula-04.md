# Respostas — Aula 04

1. fₓ = 2xy³ + y cos(xy); f_y = 3x²y² + x cos(xy).
2. fₓy = ∂/∂y(2xy³ + y cos(xy)) = 6xy² + cos(xy) − xy sen(xy). f_yx = ∂/∂x(3x²y² + x cos(xy)) = 6xy² + cos(xy) − xy sen(xy). **Iguais.**
3. fₓ = 2x = 2, f_y = 2y = 4 em (1, 2). z − 5 = 2(x − 1) + 4(y − 2) ⟹ **z = 2x + 4y − 5**.
4. f = √(x² + y²): fₓ = x/f = 3/5, f_y = 4/5 em (3, 4); f(3, 4) = 5. L = 5 + (3/5)(0,02) + (4/5)(−0,04) = 5 + 0,012 − 0,032 = **4,98** (valor exato ≈ 4,98016).
5. u_xx = (2y² − 2x²)/(x² + y²)²; u_yy = (2x² − 2y²)/(x² + y²)². Soma = **0**.
6. fₓ(0, 0) = lim [f(h, 0) − f(0, 0)]/h = 0; analogamente f_y(0, 0) = 0. **Existem.** Mas pelo exercício 2 (reta y = mx, aula 02) o limite de *f* em (0, 0) não existe, logo *f* **não é contínua** na origem e, portanto, **não é diferenciável**.
7. fₓ = yz + 2x; fₓy = z; fₓyz = **1**.
8. A = xy. dA = y dx + x dy = 20(0,1) + 10(0,1) = **3 cm²** (erro máximo estimado).
