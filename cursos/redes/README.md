# Curso de Redes de Computadores I do Zero

Esta pasta reúne um curso prático de **Redes de Computadores I**, construído a partir dos slides e das listas de exercícios da disciplina. Vai da comunicação de dados e das topologias até Ethernet, VLAN, Wi-Fi, redes ópticas, ATM, Frame Relay e SDH. O material foi criado com a ajuda de inteligência artificial (IA), que gerou as aulas, as listas de exercícios e os gabaritos, e serve como registro do meu processo de estudo.

## Estrutura

- `aulas/`: o conteúdo de cada aula em Markdown
- `listas/`: uma lista de exercícios por aula, com as questões **mais relevantes** das listas da professora (indicadas com a fonte, ex.: *P1·L3 q.14*) mais **exercícios extras** de cálculo
- `respostas/`: gabaritos resumidos de cada lista
- `praticas/`: scripts em JavaScript (Node.js) para ver os conceitos funcionando

## Como usar

1. Leia a aula, na ordem. Cada aula termina com um **Resumo**.
2. Resolva a lista da aula **no papel**, antes de abrir `respostas/`.
3. Rode os scripts de `praticas/` nas aulas que os citam. Precisa só do **Node.js 18+** (sem instalar pacotes):

```bash
cd praticas
node crc.js 101110 1001        # CRC da aula 9
node hamming.js                # distância de Hamming
node bit_stuffing.js           # enquadramento por inserção de bits
node janela_deslizante.js      # janela deslizante x para-e-espera
node paridade_2d.js            # paridade bidimensional: detecta e corrige
node baldes.js                 # leaky bucket x token bucket
node slotted_aloha.js          # eficiência do Slotted Aloha
node f_lambda.js 2.4e9 5e9     # comprimento de onda
```

## Legenda das fontes nas listas

`P1·L1`…`P1·L5` são as 5 partes da lista da P1 (física/meios, comutação/modelos, enlace/erros, acesso ao meio, Ethernet). `P2·L2` é a lista da P2 sobre STP/VLAN/Metro Ethernet. `P2·Wi-Fi` e `P2·Óptica` são as listas de redes sem fio e de redes óticas/DWDM. `P2·Docx` é a lista da P2 em Word (STP, TRILL, ATM, Frame Relay, PDH, SDH). `extra` é exercício criado para o curso.

Algumas listas da professora se repetem entre si (a lista de enlace aparece na P1 e na P2; a de acesso ao meio/Ethernet também). Para não duplicar, cada pergunta foi usada **uma vez**, e perguntas muito parecidas foram agrupadas (ex.: *P2·Wi-Fi q.6-8*).

## Pontos em que o material da disciplina destoa da literatura

Para você não ser pego de surpresa, anotei nas aulas onde os slides/listas usam um termo diferente do padrão. Na prova vale o que a professora ensinou; saber a diferença só ajuda:

| Onde | O material diz | Termo/fato usual |
|------|----------------|------------------|
| Aula 12 | campo “Tipo (ToS)” do quadro Ethernet | **EtherType**; ToS é um campo do cabeçalho **IP** |
| Aula 13 | a bridge separa domínios de broadcast **e** de colisão | a bridge separa **colisão**; broadcast só com roteador/VLAN |
| Aula 03 | 802.6 = FDDI | 802.6 é o DQDB; FDDI é padrão ANSI |
| Aula 03 | taxas em “MBps” | **Mbps** (megabits/s) |
| Aula 13 | “cut-throw” | **cut-through** |
| Aula 19 | “RTC” (lista de Wi-Fi) | **RTS** |
| Aula 20 | “FBL” (lista de redes óticas) | **FDL** (Fibre Delay Line) |
| Aula 15 | VLAN por protocolo “identificada pelo ToS” | identificada pelo **EtherType** |

Além disso, uma das listas de enlace (parte 3) vem com o cabeçalho “Redes de Computadores II”; tratei como material de Redes I.
