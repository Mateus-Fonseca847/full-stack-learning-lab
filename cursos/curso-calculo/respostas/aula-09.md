# Respostas — Aula 09

1. ∫₀¹ ∫₀² (x² + y) dy dx = ∫₀¹ (2x² + 2) dx = 2/3 + 2 = **8/3**.
2. Região: 0 ≤ x ≤ 1, x² ≤ y ≤ x. ∫₀¹ x·[y²/2]ₓ²ˣ dx = ∫₀¹ (x³/2 − x⁵/2) dx = 1/8 − 1/12 = **1/24**.
3. Região: 0 ≤ x ≤ y ≤ 1. Invertendo: ∫₀¹ ∫₀^y e^(y²) dx dy = ∫₀¹ y e^(y²) dy = [e^(y²)/2]₀¹ = **(e − 1)/2**.
4. ∫₀¹ ∫₀² (4 − x − y) dy dx = ∫₀¹ (8 − 2x − 2) dx = ∫₀¹ (6 − 2x) dx = 6 − 1 = **5**.
5. ∫₀² ∫₀^(2−x) (x + y) dy dx = ∫₀² [x(2 − x) + (2 − x)²/2] dx = ∫₀² (2 − x²/2) dx = 4 − 4/3 = **8/3**.
6. Cruzamentos: x² = 2x ⟹ x = 0 e 2. Área = ∫₀² (2x − x²) dx = 4 − 8/3 = **4/3**.
7. Região: 0 ≤ y ≤ x ≤ 1. Invertendo: ∫₀¹ ∫₀ˣ (sen x / x) dy dx = ∫₀¹ sen x dx = **1 − cos 1** ≈ 0,4597.
