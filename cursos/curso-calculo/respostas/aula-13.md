# Respostas — Aula 13

1. x = au, y = bv ⟹ J = ab. Região vira u² + v² ≤ 1 (disco unitário, área π). Área = ab·π = **πab**.
2. ∂(u, v)/∂(x, y) = |2 1; 1 −1| = −3. Logo ∂(x, y)/∂(u, v) = 1/(−3) = **−1/3** (em módulo, 1/3). Confere resolvendo: x = (u + v)/3, y = (u − 2v)/3.
3. u = y − x, v = y + x ⟹ x = (v − u)/2, y = (v + u)/2, |J| = 1/2. Região: 0 ≤ v ≤ 1, −v ≤ u ≤ v. ∫₀¹ ∫_(−v)^v (1/2) e^(u/v) du dv = ∫₀¹ (v/2)(e − 1/e) dv = **(e − 1/e)/4 = sen h(1)/2 ≈ 0,5876**.
4. u = x + y, v = x − y ⟹ |J| = 1/2. |x| + |y| ≤ 1 ⟺ |u| ≤ 1 e |v| ≤ 1. ∫₋₁¹ ∫₋₁¹ (v²)(1/2) du dv = (1/2)·2·(2/3) = **2/3**.
5. u = xy ∈ [1, 2], v = y/x ∈ [1, 2]. x = √(u/v), y = √(uv) ⟹ |J| = 1/(2v). Área = ∫₁² ∫₁² 1/(2v) dv du = **(ln 2)/2**.
6. x = ρ sen φ cos θ, y = ρ sen φ sen θ, z = ρ cos φ. O determinante 3 × 3 de ∂(x, y, z)/∂(ρ, φ, θ) dá **ρ² sen φ** (positivo para φ ∈ [0, π]).
