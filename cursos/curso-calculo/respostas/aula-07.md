# Respostas — Aula 07

1. fₓ = 3x² − 3y, f_y = 3y² − 3x. Igualando a 0: y = x² e x = y² ⟹ (0, 0) e (1, 1). fₓₓ = 6x, f_yy = 6y, fₓy = −3 ⟹ D = 36xy − 9.
   - (0, 0): D = −9 < 0 ⟹ **sela**.
   - (1, 1): D = 27 > 0 e fₓₓ = 6 > 0 ⟹ **mínimo relativo**, f(1, 1) = −1.
2. fₓ = 2x + y − 3 = 0 e f_y = x + 2y = 0 ⟹ (2, −1). fₓₓ = 2, f_yy = 2, fₓy = 1 ⟹ D = 3 > 0, fₓₓ > 0 ⟹ **mínimo relativo**, f(2, −1) = **−3**.
3. Interior: fₓ = 2x − 2 = 0, f_y = 2y = 0 ⟹ (1, 0), f = −1. Fronteira x² + y² = 4: f = 4 − 2x, x ∈ [−2, 2]; máximo 8 em x = −2 [(−2, 0)], mínimo 0 em x = 2 [(2, 0)]. Comparando: **máximo absoluto 8 em (−2, 0); mínimo absoluto −1 em (1, 0)**.
4. A = xy + 2xz + 2yz com xyz = 32 ⟹ z = 32/(xy). Por simetria x = y = s: A = s² + 128/s; A' = 2s − 128/s² = 0 ⟹ s³ = 64, s = 4, z = 2. **4 × 4 × 2**, área mínima **48**. (Vale confirmar com ∂A/∂x = ∂A/∂y = 0 sem supor simetria: dá x = y = 4.)
5. n = 4, Σx = 6, Σy = 12, Σxy = 0 + 3 + 8 + 12 = 23, Σx² = 14. m = (4·23 − 6·12)/(4·14 − 36) = 20/20 = 1. b = (12 − 6)/4 = 3/2. **y = x + 3/2**.
6. fₓₓ = 12x², f_yy = 12y², fₓy = 0 ⟹ D = 0 em (0, 0), inconclusivo. Mas f = x⁴ + y⁴ ≥ 0 = f(0, 0): é **mínimo absoluto** (e relativo).
