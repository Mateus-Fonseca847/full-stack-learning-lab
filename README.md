# Full Stack Learning Lab

Repositório dedicado ao registro da minha evolução nos estudos de desenvolvimento Full Stack.

Aqui organizo exercícios, anotações e projetos desenvolvidos durante meus estudos, com o objetivo de praticar conceitos de programação, acompanhar meu progresso e aplicar os conhecimentos adquiridos em projetos práticos.

## Objetivo

Este repositório funciona como um laboratório de aprendizado.

Ao longo dos estudos, utilizo este espaço para:

* praticar fundamentos de programação;
* registrar exercícios desenvolvidos durante cursos e estudos;
* aplicar conceitos em pequenos projetos;
* praticar Git e GitHub;
* documentar minha evolução como desenvolvedor;
* experimentar novas tecnologias e ferramentas.

### Exercícios

A pasta `Exercicios` contém códigos desenvolvidos para estudar conceitos específicos.
Novos conteúdos serão adicionados conforme avanço nos estudos.

### Mini-projetos

A pasta `mini-projetos` reúne aplicações pequenas desenvolvidas para colocar diferentes conceitos em prática.

Projetos atuais:

#### Bingo de Futebol

Jogo de associação entre jogadores de futebol e seus respectivos clubes, utilizando dados obtidos através de uma API externa.

Principais conceitos praticados:

* consumo de APIs;
* JavaScript assíncrono;
* manipulação do DOM;
* eventos;
* arrays e objetos;
* controle de estado;
* temporizadores.

#### Calculadora de IMC

Aplicação para calcular o Índice de Massa Corporal a partir das informações fornecidas pelo usuário.

Principais conceitos praticados:

* formulários;
* manipulação do DOM;
* operações matemáticas;
* condicionais;
* interação com o usuário.

#### Login Page

Interface de login desenvolvida como exercício de front-end.

Principais conceitos praticados:

* HTML semântico;
* CSS;
* formulários;
* responsividade;
* organização de interfaces.

## Tecnologias

Tecnologias presentes atualmente no repositório:

* HTML5

* GitHub

A lista será atualizada conforme novas tecnologias forem estudadas.

## Metodologia

Os códigos presentes neste repositório fazem parte do meu processo de aprendizado.

Por esse motivo, alguns projetos podem ser simples ou passar por diversas alterações ao longo do tempo. A intenção é manter registrado não apenas o resultado final, mas também minha evolução durante os estudos.
